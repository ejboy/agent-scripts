# npm-lite experiment data

The temporary project checkouts, installed dependencies, runtime packages,
captured logs, and generated measurements were removed after the experiment.
They were local, reproducible data and were not needed alongside the committed
summary in `../NPM-LITE-OPEN-SOURCE-EXPERIMENT.md`.

To reproduce the experiment, restore the three pinned project checkouts and
runtime installations described in that report, then recreate the comparison
harness from the documented method.
